# Autoplay Killer

Autoplay Killer is a global autoplay blocker by A A Hasnat and HNE Technologies. It pauses media across open tabs and helps prevent sites from restarting autoplay after the user turns it off.

Links:
- Chrome Web Store: https://chromewebstore.google.com/detail/autoplay-killer/pjehmemkchfgplmlhnlbaahhecoflaen?authuser=0&hl=en
- GitHub: https://github.com/deadsec07/autoplay-killer
- Main site: https://hnetechnologies.com/
- Creator profile: https://deadsec07.github.io/

## Features
- Global one-click ON/OFF toggle
- Pauses media in all open tabs
- Prevents future autoplay with document-start hooks
- Lightweight and privacy-friendly
